# brain

System projects for `brain.local`, the home workstation. This directory groups the deployments that run on that host.

`brain.local` refers to the target workstation on the LAN; it is not necessarily the machine where you cloned this repository.

## Projects

- [ai-station/](ai-station/) — a declarative, rootless Podman deployment for the local AI workstation.

Follow each project's README for its prerequisites, setup, and operational commands. Run host-specific commands on `brain.local`; when working from another machine, connect to that host first.

See the [repository overview](../README.md) for the overall layout and license.
